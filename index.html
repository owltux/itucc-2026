Panduan Integrasi G-Sheets

Ikuti langkah berikut untuk menghubungkan pendaftaran ini dengan Google Sheets Anda secara otomatis:

  1. Buka Google Sheets Baru dan beri nama file Anda (misal: Data ITUCC 2026).
  2. Pada menu atas, klik Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode bawaan yang ada di editor, lalu Copy & Paste kode berikut ini:
  1. Klik ikon Simpan (Save project) di bagian atas.
  2. Klik tombol biru Terapkan (Deploy) di kanan atas > pilih Deployment baru (New deployment).
  3. Klik ikon gerigi ⚙️ (Pilih jenis/Select type) > Centang Aplikasi Web (Web app).
  4. Pada bagian Akses (Who has access), ubah menjadi Siapa saja (Anyone).
  5. Klik Terapkan (Deploy). (Jika diminta otorisasi, klik "Izinkan Akses / Authorize access" dan lanjutkan peringatan keamanan Google dengan klik Advanced > Go to project).
  6. Terakhir, Copy URL Aplikasi Web (Web app URL) yang muncul dan paste ke kolom di bawah ini:

URL ini akan disimpan di browser Anda untuk keperluan ekspor data.
